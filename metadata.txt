changelog=0.4 - QGIS 4 / Qt6 release
    - Ported the whole plugin to QGIS 4 and Qt6 (PyQt6 via the qgis.PyQt shim);
      the 0.3 build only ran on QGIS 3.
    - The main dock was split into focused mixins: image browser, video browser
      and per-frame video annotation, annotation editor, GRASS, report, settings
      and dock-layout persistence.
    - GRASS GIS work now goes through one HTTP client (gt/grass_api.py): set and
      show the computational region, query rasters and backscatter, and run
      arbitrary GRASS modules from schema-driven dialogs, asynchronously as QGIS
      tasks.
    - Settings moved to config/config.yaml with a pydantic schema and per-key,
      severity-aware validation, so one stale path disables only its own feature
      instead of blocking startup. The hardcoded service URL is gone.
    - User documentation is now a MkDocs site: https://epifanio.github.io/groundtruther/
    - Python dependencies are loaded from a virtualenv beside the plugin; a
      Plugin Manager install does not create one yet, so this release stays
      experimental. See the install page in the documentation.
