GroundTruther

What changed since the paper

A QGIS plugin for seafloor characterization — multibeam acoustics, seafloor imagery & survey video, together on one map.

Development update · 2026 · v0.4 · QGIS 4 / Qt 6

Recap — what it is

  • Runs inside QGIS as a dock-based toolset
  • Joins three data worlds on one map:
    • MBES bathymetry + backscatter (ARA)
    • Seafloor imagery (HabCam-style stills)
    • Survey video with per-frame GPS
  • Ground-truth annotation → statistics → KMZ / HTML reports
  • Remote GRASS GIS service for geoprocessing

QGIS 4 / Qt 6 support platform

  • Full port to QGIS 4.0+ / Qt 6 (system Python 3.14)
  • Qt 6 API rework: scoped enums, exec_ → exec
  • Fixed Qt 6 dock-walk crashes (register docks with main window)
  • OpenGL 3-D viewer made Qt 6-safe (PyOpenGL context)
  • Wayland: launch QT_QPA_PLATFORM=xcb for floating docks

Streamlined installation setup

  • QGIS 4 runs on system Python (PEP-668, no pip) — handled cleanly:
    • Plugin deps live in a .venv beside the source
    • _bootstrap_venv() appends it to sys.path at load
  • Install = symlink the repo into the QGIS profile + enable
  • Fixed missing runtime deps & venv bootstrap → one-step setup
  • Video decode via PyAV (bundled FFmpeg) — no system-codec hunt

Code refactoring — modular & maintainable internals

  • Thin orchestrator + focused mixins — dockwidget ≈ 240 lines:
    image browservideo browser video annotationGRASSreport settingslayoutsession
  • Stateless, testable core (gt/) — no Qt, unit-tested:
    grass_apiimage_manager video_managertask_runner mbes_fields ✨video_reader ✨session_state ✨
  • A growing pytest suite (unit / GUI-offscreen / integration)

New FastGIS API (GRASS backend) backend

  • Legacy flat, unauthenticated endpoint → api.fastgis.eu
  • Authenticated (X-API-Key), built on an environment model (env_id)
  • Schema-driven module dialogs — any GRASS module from its interface; async via QgsTask
  • GRASS Tools is now an undockable QGIS panel: module picker, push rasters back to QGIS, show/hide computational region

Feature — MBES query builder new

  • Draw a sampling unit (ellipse / rectangle) on the soundings
  • ARA scatterplot · 3-D surface · histograms · stats · in-shape images
  • Multi-level backscatter (new): auto-detects every BSWG-2015 level (raw→RL→TL→area→AVG), back-compatible with the legacy format
  • Beam-side filtering (Raw / Port / Starboard / Fold) fixed

Feature — video player new

  • Frame-accurate player docked in QGIS, driven from the metadata track
  • Interlaced support (new): PyAV + yadif — fixes the FFmpeg-8 black-frame failure
  • Geo-link to map: canvas follows the frame at a fixed, CRS-independent scale
  • GPS track as a persistent GeoJSON layer — no scratch warning, auto-regenerated

Video & image annotation new

Bug-fix roundup (selected)

  • 3-D WGL viewer blank on Qt 6 → fixed (PyOpenGL context)
  • ARA beam radios (L / R / Fold) had no effect → fixed
  • KMZ save crashed on un-generated products → guarded + de-duplicated
  • Docks / video player came back undocked → restoreState
  • Geo-link marker moved but map didn't follow → throttle fix
  • Zoom was projection-dependent → map scale (1:N), CRS-independent
  • Interlaced video → black frames → PyAV / yadif
  • Stale / broken track reference on reload → auto-regenerate

Is this a unique tool?

Yes — the integration is the differentiator.

  • Most workflows are siloed: acoustics, image annotation, video review, GIS — all separate
  • GroundTruther puts MBES + imagery + video + annotation + GRASS + reporting on one QGIS map, free & open source
  • Cloud GRASS backend keeps heavy geoprocessing server-side
  • Open formats throughout (Parquet · GeoJSON · KMZ · CSV / .log)

Not a replacement for specialist acoustic suites — a connective, ground-truthing layer that ties them together.

What's next?
