GroundTruther
=============

**The GroundTruther documentation lives on the documentation site:**

    https://epifanio.github.io/groundtruther/

This Sphinx tree is a leftover of the QGIS Plugin Builder template. It is kept
only because ``Makefile`` (``make doc`` / ``make deploy``) and ``pb_tool.cfg``
still expect ``help/build/html`` to exist when packaging the plugin. **Do not add
documentation here** — it is not published anywhere and would only duplicate, and
drift from, the site.
